# cctapi 单实例运行手册

> 文档状态：草稿
>
> 能力状态：TARGET（完成恢复演练后转为 CURRENT）
>
> 适用范围：Windows 单实例、SQLite、`D:\ct\project`、端口 `3008`

## 1. 边界

本手册描述当前可执行的单实例构建、备份、发布、回滚和恢复流程。它不声明 Redis、多实例、云 VPC、WAF、KMS/Vault、自动日志归档或自动灾备已经上线；这些仍属于 `TARGET` 或 `DEFERRED`。

## 2. 发布前提

- 工作目录必须是 `D:\ct\project`。
- 构建使用 Go 1.26.5 或同补丁线更高版本。
- Windows CGO 使用 `D:\ct\tools\w64devkit-1.23.0\bin`。
- 前端必须先生成 `web\build\default`，再构建 Go 二进制。
- 不得把 `.env`、API key、Token、管理员密码写入日志或验收证据。
- 发布 SHA 必须通过《发布门禁》中的 R1、R2；真实运行验收完成后才能通过 R3、R4。

## 3. 本地预检

```powershell
Set-Location D:\ct\project
powershell -ExecutionPolicy Bypass -File scripts\release-preflight.ps1
```

该脚本执行前端 lint、Vitest、Vite、Storybook，执行 Go 全包测试、scoped race、vet、build 和 `git diff --check`。它不代替 GitHub CI，也不代替真实协议验收。

## 4. 构建候选二进制

```powershell
$env:CGO_ENABLED='1'
$env:PATH='D:\ct\tools\w64devkit-1.23.0\bin;' + $env:PATH

Set-Location D:\ct\project\web\default
npm run build

Set-Location D:\ct\project
& 'D:\ct\tools\go\bin\go.exe' build -o one-api.exe.new .

$targetSha = (git rev-parse HEAD).Trim()
$candidateHash = (Get-FileHash -Algorithm SHA256 -LiteralPath 'one-api.exe.new').Hash
[ordered]@{
    sha = $targetSha
    sha256 = $candidateHash
    built_at = (Get-Date).ToUniversalTime().ToString('o')
} | ConvertTo-Json | Set-Content -Encoding UTF8 'one-api.exe.new.manifest.json'
```

不要直接覆盖正在运行的 `one-api.exe`。

## 5. 停机一致性备份

SQLite 文件复制只在服务停止后执行，避免得到不一致的数据库副本。

```powershell
Set-Location D:\ct\project
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
$backup = Join-Path 'backups' $stamp
New-Item -ItemType Directory -Path $backup -Force | Out-Null

$listeners = @(Get-NetTCPConnection -LocalPort 3008 -State Listen -ErrorAction SilentlyContinue)
if ($listeners.Count -gt 1) {
    throw 'multiple listeners found on port 3008; refusing to stop any process'
}
if ($listeners.Count -eq 1) {
    $pidToStop = $listeners[0].OwningProcess
    $process = Get-CimInstance Win32_Process -Filter "ProcessId = $pidToStop"
    $expectedExe = (Resolve-Path -LiteralPath 'one-api.exe').Path
    if (-not $process.ExecutablePath -or
        -not [string]::Equals($process.ExecutablePath, $expectedExe, [System.StringComparison]::OrdinalIgnoreCase) -or
        $process.CommandLine -notmatch '(?:^|\s)--port(?:\s+|=)3008(?:\s|$)') {
        throw "port 3008 is owned by an unexpected process; refusing to stop PID $pidToStop"
    }
    Stop-Process -Id $pidToStop -Force
    Start-Sleep -Seconds 2
}

Copy-Item -LiteralPath 'one-api.db' -Destination (Join-Path $backup 'one-api.db')
if (Test-Path -LiteralPath 'fallback.json') {
    Copy-Item -LiteralPath 'fallback.json' -Destination (Join-Path $backup 'fallback.json')
}
if (Test-Path -LiteralPath 'one-api.exe') {
    Copy-Item -LiteralPath 'one-api.exe' -Destination (Join-Path $backup 'one-api.exe')
}
```

`.env` 如需备份，必须进入受控的加密存储，不进入普通 `backups` 目录、仓库或验收证据。

## 6. 替换与启动

```powershell
Set-Location D:\ct\project
$manifest = Get-Content -Raw -LiteralPath 'one-api.exe.new.manifest.json' | ConvertFrom-Json
$currentSha = (git rev-parse HEAD).Trim()
$actualHash = (Get-FileHash -Algorithm SHA256 -LiteralPath 'one-api.exe.new').Hash
if ($manifest.sha -ne $currentSha -or $manifest.sha256 -ne $actualHash) {
    throw 'candidate binary SHA or hash does not match the current target revision'
}
if (Get-NetTCPConnection -LocalPort 3008 -State Listen -ErrorAction SilentlyContinue) {
    throw 'port 3008 is still listening; refusing to replace the binary'
}
Move-Item -LiteralPath 'one-api.exe.new' -Destination 'one-api.exe' -Force

Start-Process -FilePath '.\one-api.exe' `
    -ArgumentList '--port', '3008' `
    -WorkingDirectory 'D:\ct\project' `
    -WindowStyle Hidden `
    -RedirectStandardOutput 'one-api.stdout.log' `
    -RedirectStandardError 'one-api.stderr.log'

$deadline = (Get-Date).AddSeconds(30)
do {
    Start-Sleep -Seconds 1
    try {
        $response = Invoke-WebRequest -UseBasicParsing -Uri 'http://127.0.0.1:3008/' -TimeoutSec 3
        if ($response.StatusCode -eq 200) { break }
    } catch {}
} while ((Get-Date) -lt $deadline)

if (-not $response -or $response.StatusCode -ne 200) {
    throw 'one-api did not become healthy on port 3008'
}
```

## 7. 回滚

如果启动检查或 R3 验收失败：

1. 停止端口 `3008` 的当前进程。
2. 从本次 `backups\<timestamp>\one-api.exe` 恢复旧二进制。
3. 仅在确认数据库迁移或数据写入导致不兼容时，才恢复 `one-api.db`；恢复数据库会丢弃备份之后的数据。
4. 启动旧二进制并重新检查 HTTP 200。
5. 记录失败 SHA、错误类别和脱敏日志，不记录原始上游正文或凭据。

## 8. 恢复演练

至少在正式发布前执行一次：

- 用备份数据库在隔离目录启动同版本二进制。
- 确认管理员登录、虚拟模型配置、free pool 运行状态可读取。
- 执行一次非流式和流式测试请求。
- 记录实际 RPO/RTO；在没有演练证据前，`RPO <= 24h`、`RTO <= 30min` 仍为 `TARGET`。
